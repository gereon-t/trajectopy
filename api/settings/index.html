    Settings¶

    Processing and plot settings, and the options they take. Options are enumerations; wherever an option is expected, its value can also be given as a string (case-insensitive). See the user guide for a description of every setting.

    Provides serialization/deserialization functionality to and from dictionaries, JSON strings, and files.

    def update_from_dict(self, dct: dict) -> None:
    """Updates settings from a dictionary.

    Attributes missing from the dictionary keep their current value. Unknown attributes
    are ignored with a warning. The update is atomic: if any value is invalid, the
    settings remain unchanged.

    Args:
        dct: Dictionary containing updated settings data

    Raises:
        TypeError: If a value does not match the declared attribute type

    Examples:
        >>> import trajectopy as tpy
        >>> settings = tpy.MatchingSettings()
        >>> settings.update_from_dict({"max_time_diff": 0.05})
        >>> settings.max_time_diff
        0.05
    """
    updates = self._decoded_updates(dct)  # validates everything before anything is changed
    for attribute_name, value in updates.items():
        if isinstance(value, Settings):
            # update nested settings in place, so that references held elsewhere stay up to date
            getattr(self, attribute_name)._assign_from(value)
        else:
            setattr(self, attribute_name, value)

    Bases: Settings

    Configuration for alignment preprocessing filters.

    Attributes:

    • min_speed (float) –

      Only poses with at least this speed are considered for alignment (meters/second); 0 keeps standstills. Defaults to 0.0.

    • time_start (float) –

      Only poses from this time on are considered. Timestamp is in seconds relative to first common timestamp. Defaults to 0.0.

    • time_end (float) –

      Only poses up to this time are considered (0 = until the end). Timestamp is in seconds relative to first common timestamp. Defaults to 0.0.

    • max_samples (int) –

      Maximum number of matched poses used for the alignment. If more poses are available, a new random subset of this size is drawn on each run. Set to 0 to use all poses. Defaults to 5000.

    Examples:

    >>> import trajectopy as tpy
>>> preprocessing = tpy.AlignmentPreprocessing(min_speed=1.0, max_samples=0)  # moving poses, all of them

    @classmethod
def from_bool_list(cls, bool_list: list[bool]) -> "AlignmentEstimationSettings":
    """Creates settings from a list of boolean values.

    Args:
        bool_list: 14 enable flags in the order translation x, y, z, rotation x, y, z, scale, time shift,
            lever arm x, y, z and sensor rotation x, y, z (the order of
            ``AlignmentParameters.enabled_bool_list`` followed by ``SensorRotationParameters.enabled_bool_list``).
            The sensor rotation is estimated if any of the last three is True.

    Returns:
        AlignmentEstimationSettings: New settings instance

    Raises:
        ValueError: If bool_list length is not 14
    """
    if len(bool_list) != 14:
        raise ValueError(
            f"Size mismatch: bool_list must have length 14 (Number of configurable parameters) (got {len(bool_list)})"
        )

    return AlignmentEstimationSettings(
        translation_x=bool_list[0],
        translation_y=bool_list[1],

    Options¶

    MatchingMethod ¶

    Bases: OptionEnum

    Method for matching corresponding poses of two trajectories (see trajectopy.match_trajectories).

    Each option can also be given as its value, e.g. method="nearest_temporal" (case-insensitive).

    Attributes:

    • INTERPOLATION –

      "interpolation": the trajectory is interpolated at the timestamps of the reference; linearly for the positions, by SLERP for the orientations. The default.

    • NEAREST_TEMPORAL –

      "nearest_temporal": the pose with the nearest timestamp, within max_time_diff.

    • NEAREST_SPATIAL –

      "nearest_spatial": the nearest position, within max_distance; needs no common time reference.

    • NEAREST_SPATIAL_INTERPOLATED –

      "nearest_spatial_interpolated": the projection onto a line fitted through the k_nearest nearest positions of the reference.

    Examples:

    >>> import trajectopy as tpy
>>> tpy.MatchingMethod("Nearest_Temporal")
<MatchingMethod.NEAREST_TEMPORAL: 'nearest_temporal'>
